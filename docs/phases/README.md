# Bitácora por fase

Cada fase cerrada tiene un archivo aquí: `phase-0.md`, `phase-1.md`, etc.

## Qué va en cada bitácora

- **Qué se construyó**: lista concreta de archivos/módulos creados o cambiados.
- **Decisiones tomadas durante la fase**: pequeñas, las grandes van a `DECISIONS.md` en la raíz.
- **Comandos útiles**: cómo correr, testear, poblar data, etc.
- **Gotchas / cosas raras**: cualquier cosa que sorprendería a la próxima sesión.
- **Deuda técnica dejada**: TODOs conscientes que quedaron abiertos.
- **Cómo verificar que la fase quedó bien**: pasos concretos de smoke test.
